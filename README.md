# PixelForge: Guia de Setup Gamer

Guia interativo em português para auxiliar jogadores a compreenderem conceitos de hardware, desempenho gráfico e periféricos sem depender de jargões técnicos complexos.

## Histórico de Versões (Evolução do Projeto)
- **v1.0 (`etapa-1-wireframe.html`):** Esqueleto estrutural (wireframe de baixa fidelidade) definindo o grid principal, cabeçalho fixo e hierarquia semântica.
- **v2.0 (`etapa-2-modulos.html`):** Implementação dos módulos funcionais em JavaScript (glossário com filtro por abas WAI-ARIA, busca dinâmica, carrossel e formulário).
- **v3.0 (`etapa-3-identidade-visual.html`):** Aplicação da paleta de cores baseada em psicologia das cores e validação de contraste WCAG AAA, tipografia Chakra Petch / Figtree e ilustrações SVG.
- **v4.0 (`index.html`):** Versão final completa contendo Modo Escuro, Painel de Acessibilidade (alto contraste, ajuste de fonte, pausa de animações), tela de login simulada e persistência via `localStorage`.
